## Method

1. **Define the claim** in one or two sentences.
2. **Gather evidence** from the database, with chapter numbers; SBS entries via
   `sbs_index`, read on the wiki.
3. **Find the mechanism**, not just the pattern: explain *how*, step by step.
4. **Score competing explanations** against the same evidence.
5. **Name the weak points** honestly.
6. **Write tests:** what would kill it, what would confirm it.
7. **Re-check** when a new arc touches the topic; update "Last checked against".

Wiki summaries can carry hindsight from later edits, so weight events over wording.
